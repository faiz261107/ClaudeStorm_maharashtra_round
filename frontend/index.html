Re:Learn doesn't tell you that you're wrong.
It tells you why, fixes that, and checks that the fix stuck.

Most platforms grade right/wrong and show the solution. That throws away the most useful thing a wrong answer carries: which mistaken idea produced it.

Same wrong answer, different problems

StudentPickedExplanationReal misconception
AAcceleration = 0“It stops at the top, so velocity is zero.”Velocity–acceleration confusion
RAcceleration = 0“The force of the throw has run out.”Impetus
S9.8 m/s² down (correct)“It is still slowing down because of the throw force.”Impetus, hidden behind a right answer

A traditional LMS marks A and R identically and marks S as fully correct. Re:Learn separates all three — try it on question 1.

The loop

  1. Answer — choose an option, rate your confidence, explain in a sentence.
  2. Diagnose — a trained classifier reads the answer and the explanation. The chosen option narrows the candidates; the words decide between them. Weak evidence → it asks rather than guesses.
  3. Fix — an explanation, worked example and physics animation built for that misconception.
  4. Verify — a transfer question in a new context. Resolved only if the answer is right and the reasoning is clean, in two contexts, plus a delayed recheck later in the session.
  5. Track — your thinking map keeps each idea as active, improving, resolved or recurring.

Under the hood

  • 5 misconceptions from physics-education research (Force Concept Inventory), 30 questions, 15 transfer probes. Every wrong option maps to the misconceptions that can produce it.
  • 1,800+ labelled (question, answer, explanation) rows: hand-written seeds plus student-style paraphrases, including hard cases on purpose.
  • Three input modes: multiple choice + explanation, numeric working, and a free-body diagram you draw — plus voice dictation and a photo of handwritten working (OCR).
  • Classifier: TF-IDF + logistic regression by default (trains in a second, <5 ms per diagnosis); optional fine-tuned DeBERTa-v3.
  • A tutor reply to every explanation — NLP reads your sentence (key phrase, concepts mentioned, hedging) and writes back in natural language; generated by an LLM when an API key is configured, rule-based otherwise.
  • Cross-session memory: resolved ideas are re-checked at the start of your next session.
  • Answer prior, abstain threshold, and a description-embedding fallback so a brand-new misconception works with no retraining.
  • FastAPI + SQLite. Answer keys never leave the server.
